# 动画事件桥接

本接口只负责通知投掷阶段、让出姿势绘制；不要求任何特定第三方动画库，也不宣称自动兼容所有动画模组。

## 事件总线

订阅 `MinecraftForge.EVENT_BUS` 上的：

`cn.blockforge.generated.moda3c26b8e.api.TorchAnimationEvent`

常用访问器：

- `getPlayer()`：投掷玩家。
- `getHand()`：主手或副手。物理左右手需结合 `Player#getMainArm()` 判断。
- `getAnimationPhase()`：`START`、`RELEASE`、`CANCEL`。
- `getCharge()`：0 到 1 的力度。

`START` 在超过 10 游戏刻的阈值、真正进入蓄力时触发；`RELEASE` 只在服务器成功生成投射物后触发；短按或中断会走取消分支。客户端为本机蓄力提供预测，服务器回执不会重复触发同一个开始阶段。

普通阶段事件不可取消。在服务器逻辑线程和客户端主线程分别发布；一体化服务器会同时有两个逻辑端。**做动画时必须检查 `event.getPlayer().level().isClientSide`，只处理客户端。**

## 姿势让出事件

`TorchAnimationEvent.Pose` 继承上面的事件，额外提供：

- `isFirstPerson()`：是否第一人称。
- `getPartialTick()`：渲染插值。
- `setCanceled(true)`：跳过本模组本次姿势，不取消实际投掷或更改库存。

每次第一/第三人称绘制前发布。它会同时匹配父事件订阅器，处理阶段通知时应排除 `Pose`，避免每帧重复开始第三方动画。

```java
import cn.blockforge.generated.moda3c26b8e.api.TorchAnimationEvent;
import net.minecraftforge.eventbus.api.SubscribeEvent;

public final class TorchAnimationBridge {
    @SubscribeEvent
    public static void onPhase(TorchAnimationEvent event) {
        if (event instanceof TorchAnimationEvent.Pose) return;
        if (!event.getPlayer().level().isClientSide) return;
        switch (event.getAnimationPhase()) {
            case START -> {
                // 在这里启动自己的后摆或蓄力动画。
            }
            case RELEASE -> {
                // 在这里按 event.getCharge() 播放过肩前甩。
            }
            case CANCEL -> {
                // 在这里清理蓄力动画并恢复姿势。
            }
        }
    }

    @SubscribeEvent
    public static void onPose(TorchAnimationEvent.Pose event) {
        if (event.getPlayer().level().isClientSide) {
            event.setCanceled(true);
            // 自己的渲染钩子负责应用对应的姿势。
        }
    }
}
```

将订阅器注册到 Forge 游戏事件总线。自己的客户端渲染代码要留在客户端专用类中，不要让专用服务器加载 `net.minecraft.client` 类。

也可以让玩家在客户端配置设置 `animation = "EXTERNAL"`。此时阶段和姿势事件仍发布，但本模组不覆盖玩家姿势。`VANILLA` 同样不覆盖姿势，仅保留原版挥臂。原版挥臂用于通用投掷反馈，不属于可取消的自定义姿势。

## 实现边界

- 网络控制只发送开始、松手、取消和所用手，不接受客户端自报的力度、坐标、物品数量。
- 投掷力度、库存消耗、实体生成和方块放置全部由服务端决定。
- 自定义姿势只改实际投掷那一条手臂；游泳、鞘翅滑翔和睡觉时不套过肩姿势。
- 服务器追踪范围内可见的玩家会收到阶段同步，新进入追踪范围的玩家会补收当前蓄力阶段。
- 客户端退出、维度切换、玩家消失和动画到期时清理本模组状态；第三方接管方也应实现相应清理。
- 火把模型引用原版资源，无自带 PNG；资源包更换火把外观时飞行外观也会跟随。
